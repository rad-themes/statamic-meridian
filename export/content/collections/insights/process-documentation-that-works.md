  A large manual can be impressive and still be ignored. People need a short path through the next action and the exceptions that change it.

  Start with the trigger, the owner, the expected output, and what to do when something is missing. Link to detail only where it helps.

  Review the document with the team that uses it, then update it when the work changes.
